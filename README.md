# Dhruv_Arora_CSE-AI-ML-SECE_Sentiment-Analysis-On-Union-Budget-Of-India
This project involved performing sentiment analysis on public and media reactions to the Union Budget of India using Natural Language Processing (NLP) techniques. We collected data from social media platforms and applied machine learning algorithms to classify sentiments as positive, negative, or neutral. The goal was to gain insights into public perception and evaluate the impact of budget announcements on different sectors. Tools and libraries used included Python, Pandas, Scikit-learn, and NLTK.
